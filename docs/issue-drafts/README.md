# Issue Drafts

These are **starting-point outlines** for the Design Leads. They are
deliberately topic-agnostic. Rewrite them for the agreed project, then open
them on GitHub **under your own account** using the "Task" issue template, so
that the contribution is credited to you. After that, delete the draft or leave
it as reference.
